# Vagartha Yoga production design review

## Audit
- Repetitive self-care slogans obscured concrete class information.
- Floating boxed navigation, pastel panels and icon tiles resembled a general wellness template.
- Booking buttons competed in the hero, story, promotional sections, footer and fixed mobile strip.
- A pinned 1,600px scroll segment and continuous canvas drawing contradicted the new motion brief.
- Time-of-day story labels could be mistaken for a teaching schedule.
- Contact only opened an email app, with no validation or delivery feedback.
- Metadata used the old .in address and lacked a complete production SEO/security setup.

## Direction
A teacher's practice notebook: paper #F6F3EA, forest #263D32, clay #8B4935, stone #D8D4C7, muted text #596258.
Cormorant Garamond regular/italic headings; DM Sans regular/medium UI and body. Existing locally bundled fonts now use next/font/local with swap and preload.
Type scale: 11/13/14/16px UI/body, 28–38px small headings, 44–68px section headings, 64–102px hero. Body prose is capped at 65ch; side columns and mobile naturally wrap shorter.
Spacing: 8, 16, 24, 32, 48, 64, 96, 128px. Mobile section spacing 72px.
Solid surfaces, ruled rows, a single still illustration, a typographic teacher introduction, no invented portrait.
Native scrolling. Only transform/opacity motion, 200ms, cubic-bezier(.22,.68,.2,1). Reduced motion removes it.

## Scope and provenance
The September production brief supersedes website-plan.txt / improvement.txt wherever they request lavender, pinning, ambient motion, or frontend-only mailto delivery.
The original files remain as historical inputs. The pixel renderer is retained as unused source; it is not imported or sent to visitors.
The existing generated terrace illustration is reused, with an explicit illustration caption. It does not depict a real venue.
Name, professional experience, PGDYT, online personal training, practice types and regions come from website-plan.txt. First-person copy is an editorial draft for Girija to approve.
The free introductory class is retained from the supplied original brief. Its current terms should be confirmed along with the other business facts before launch.
No testimonials, schedules, medical outcome claims or credentials have been invented.
